# ИИ-агент «Анализ организационной структуры и функционала» · Demo Day

Презентация проекта Optimus / OrgScope (HackAlem AI 2026, задача 1, Казахтелеком). Короткий питч на 3 минуты: 7 слайдов по критериям жюри, в финале ролик о проекте. Полная версия: 14 слайдов по критериям жюри, настоящие экраны продукта, ролик интерфейса, переключатель русский / английский. Вторая версия — с анимированными артефактами.

## Как открыть

- Локально: открыть `index.html` (главная с кнопками), `presentation.html` (питч на 3 минуты, это основная ссылка), `presentation-full.html` (полная презентация) или `artifacts.html` (галереи и видео). Нужен интернет для шрифтов Google Fonts.
- Управление: стрелки ← → или клик — листать; `L` — переключить язык; `Home` / `End` — первый и последний слайд. В питче на слайде с роликом пробел или клик ставят видео на паузу.
- Язык можно задать ссылкой: `presentation.html#en` или `presentation.html#ru` (так же для `presentation-full.html`).

## Деплой на Vercel

Корень проекта — эта папка. Статический сайт: `index.html` → главная, `presentation.html` (питч), `presentation-full.html`, `artifacts.html`, `drafts/`, `video/`.

```bash
vercel --prod
```
