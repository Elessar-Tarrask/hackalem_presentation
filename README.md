# OrgScope · Demo Day presentation

Презентация проекта Optimus / OrgScope (HackAlem AI 2026, задача 1, Казахтелеком): 14 слайдов, один HTML-файл, анимированные артефакты, переключатель русский / английский.

## Как открыть

- Локально: открыть `index.html` в браузере (нужен интернет один раз, для шрифтов Google Fonts).
- Управление: стрелки ← → или клик — листать; `L` — переключить язык; `Home` / `End` — первый и последний слайд.
- Язык можно задать ссылкой: `index.html#en` или `index.html#ru`.

## Деплой на Vercel

Корень проекта — эта папка. `vercel.json` отдаёт `index.html` как статический сайт; `.vercelignore` исключает черновики и видео.

```bash
vercel --prod
```

## Структура

| Путь | Что это |
|---|---|
| `index.html` | презентация, самодостаточный файл со встроенными скриншотами |
| `vercel.json`, `.vercelignore` | настройки статического деплоя |
| `video/` | ролики о проекте, русский и английский (46 с, 1920×1080, музыка) и постеры |
| `drafts/` | галереи вариантов артефактов, по которым выбирались финальные слайды |
| `orgscope-demo-day.html` | та же презентация в виде фрагмента для публикации артефактом Claude |

## Что внутри слайдов

Все числа, названия подразделений, номера пунктов и цитаты взяты из контрольного анализа (редакции 8 и 9 положения о внутреннем аудите): 6 подразделений, 450 и 453 пункта, 11 возможных потерь, 5 дублирований, 1 конфликт интересов, 20 нормативных оснований из трёх действующих актов с adilet.zan.kz.
