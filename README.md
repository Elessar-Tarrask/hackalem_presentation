# OrgScope · Demo Day presentation

Презентация проекта Optimus / OrgScope (HackAlem AI 2026, задача 1, Казахтелеком): 14 слайдов по критериям жюри, настоящие экраны продукта, ролик интерфейса, переключатель русский / английский. Вторая версия — с анимированными артефактами.

## Как открыть

- Локально: открыть `index.html` (главная с двумя кнопками), `presentation.html` (презентация) или `artifacts.html` (галереи и видео). Нужен интернет для шрифтов Google Fonts.
- Управление: стрелки ← → или клик — листать; `L` — переключить язык; `Home` / `End` — первый и последний слайд.
- Язык можно задать ссылкой: `presentation.html#en` или `presentation.html#ru`.

## Деплой на Vercel

Корень проекта — эта папка. Статический сайт: `index.html` → главная, `presentation.html`, `artifacts.html`, `drafts/`, `video/`.

```bash
vercel --prod
```

## Структура

| Путь | Что это |
|---|---|
| `index.html` | главная страница с кнопками «Презентация» и «Артефакты» |
| `presentation.html` | основная презентация по критериям жюри: настоящие экраны и ролик интерфейса, без рисованных артефактов |
| `presentation-artifacts.html` | версия с анимированными артефактами |
| `src/classic.html` | исходник основной презентации до вставки скриншотов |
| `artifacts.html` | галереи вариантов и ролики |
| `vercel.json`, `.vercelignore` | настройки статического деплоя |
| `video/` | `orgscope-ui-*.mp4` прогон интерфейса с подписями (65 с); `orgscope-*.mp4` ролики о проекте с музыкой (46 с); постеры |
| `drafts/` | галереи вариантов артефактов, по которым выбирались финальные слайды |
| `orgscope-classic.html`, `orgscope-artifacts.html` | те же презентации в виде фрагментов для публикации артефактами Claude |

## Что внутри слайдов

Все числа, названия подразделений, номера пунктов и цитаты взяты из контрольного анализа (редакции 8 и 9 положения о внутреннем аудите): 6 подразделений, 450 и 453 пункта, 11 возможных потерь, 5 дублирований, 1 конфликт интересов, 20 нормативных оснований из трёх действующих актов с adilet.zan.kz. Экраны продукта — настоящие.
